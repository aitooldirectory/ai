# ai
Curated list of top AI tool directories

## 🧭 Top AI Tool Directories

Discover, explore, and submit to the best AI tool directories—perfect for keeping up with the latest in AI tools, frameworks, and solutions.

### 🌍 Web-Based Directories

- **Futurepedia** – Large resource with 4000+ AI tools, frequent updates, and user-driven reviews.
- **Toolify.ai** – Modern, categorized AI platform with community features and trend tracking.
- **Aixploria.com** – Diverse collection with detailed tool profiles and collaborative content.
- **OpenTools.ai** – 10,000+ categorized tools with daily updates and trend insights.
- **OpenFuture.ai** – Wide, fast searchable tool library and strong community feedback.
- **There’s an AI For That** – “Search engine” for AI tools covering all use cases.

### 📚 GitHub Curated Lists

- [best-of-ai/ai-directories](https://github.com/best-of-ai/ai-directories) – Awesome list referencing dozens of directories (highly recommended).
- [ozgrozer/top-ai-directories](https://github.com/ozgrozer/top-ai-directories) – Simple, continually updated AI directory list.
- [mahseema/awesome-ai-tools](https://github.com/mahseema/awesome-ai-tools) – Comprehensive curation of AI tools and libraries.
- [aitoollist/awesome-ai-tool-list](https://github.com/aitoollist/awesome-ai-tool-list) (used by [AIToolList.org](https://www.aitoollist.org/)) – Community-driven, filterable data source for web and repo tools.
- [lakey009/AI-Tools-List](https://github.com/lakey009/AI-Tools-List) – 19,000+ tools, largest raw collection by volume.
- [ToolkitlyAI/awesome-ai-tools](https://github.com/ToolkitlyAI/awesome-ai-tools) – 650+ productivity and creativity tools with invite for PRs.
- [pranavp10/aidetective](https://github.com/pranavp10/aidetective) – Lists and aggregates top AI SaaS products.

### 🏷 Specialized and Community Projects

- [lumpinif/AI-App-Station](https://github.com/lumpinif/AI-App-Station) – AI app store-style project.
- [videosdk-community/ai-app-directory](https://github.com/videosdk-community/ai-app-directory) – Apps focused on writing, marketing, audio, and video AI.
- [LichAmnesia/awesome-ai-tools-dataset](https://github.com/LichAmnesia/awesome-ai-tools-dataset) – 3,000+ well-structured entries as a data source for [aidevelopify.org](https://aidevelopify.org/).
- [nathanleelyd/myaibot.ai](https://github.com/nathanleelyd/myaibot.ai) – Community-driven curation and submissions.
- [tejasrsuthar/awesome-ai-tools](https://github.com/tejasrsuthar/awesome-ai-tools) – Variety of AI frameworks and models.
- [AI-Tools-Inc/awesome-ai-tools](https://github.com/AI-Tools-Inc/awesome-ai-tools) – Workflow automation and productivity focus.
